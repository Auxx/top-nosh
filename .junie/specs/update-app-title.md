# Update App Title

The `title` tag of `web` project should be updated to reflect the new name of
the current page.

## Requirements

- Automatically update the title on navigation.
- Prefix all titles with `Top Nosh - `.
- `LoginPage` should have `Login` title.
- `OnboardPage` should have `Onboarding` title.
- `PasswordChangePage` should have `Change your password` title.
- `LandingPage` should have `Dashboard` title.
- `RecipeListPage` should have `Recipes` title.
- `RecipeDetailsPage` should have a recipe name in the title.
- `EditRecipePage` should have `Edit` followed by the recipe name in the title.
- `CreateRecipePage` should have `Create new recipe` title.
- `SharedRecipePage` should have a recipe name in the title.
- `ShoppingListPage` should have `Shopping Lists` title.
- `ShoppingListDetailsPage` should have Shopping List name in the title or
  `Create new shopping list` if the name is empty.
