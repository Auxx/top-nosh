# Create Front End Configuration Endpoint

`web` project loads its configuration on startup by fetching
`/assets/app.properties` file. This file only exists in the development
environment. It should be generated by an endpoint in `api` project in a
production environment.

## API requirements

- Create a new controller called `Configuration`.
- Create a new `GET` endpoint called `webProperties` which maps to
  `/assets/app.properties`. It should be publicly available.
- Add a global prefix exception for `webProperties` endpoint in
  `apps/api/src/main.ts` to ensure correct path mapping.
- The response is a text file in dotenv format.
- `PRODUCTION` key should always be present and should be set to `true`.
- `API_URL` key should always be present and should be set to the value of
  `CORS_ORIGIN` environment variable.
