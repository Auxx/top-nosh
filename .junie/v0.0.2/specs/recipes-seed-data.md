# Recipes seed data

Add seed data to populate the recipes table.

## Seed data requirements

- Add one recipe named `Pizza`, with servings of 4, cusine of `Italian` and
  category of `Pizza`.
- Add one stage to the recipe named `Main`.
- Add the following ingredients to this stage:
    - 200g dough
    - 150g toppings
- Add the following cooking step to the stage:
    - Add toppings to the dough.
